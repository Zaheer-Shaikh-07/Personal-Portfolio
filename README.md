🌐 Personal Portfolio Website

This is my personal portfolio website built using React, Vite, and Tailwind CSS.
It showcases my skills, projects, and provides an easy way to connect with me.

🚀 Features

⚡ Fast & Responsive – Built with Vite + Tailwind for speed.

🎨 Modern UI – Smooth animations with Framer Motion.

🛠️ Skills Section – Filterable skill categories with progress bars.

📂 Projects Showcase – With images, descriptions, and links.

📞 Contact Form – Easy way to connect via email/social links.

📑 Resume Section – Quick download option for my CV.

🛠️ Tech Stack

Frontend: React (Vite)

Styling: Tailwind CSS

Animations: Framer Motion

Icons: React Icons / Lucide Icons

Deployment: Netlify 


⚙️ Installation & Setup

Clone the repo:

git clone https://github.com/Zaheer-Shaikh-07/Personal-Portfolio.git
cd portfolio


Install dependencies:

npm install


Start development server:

npm run dev
